# VRホラーオムニバス（全3舞台・12代表パターン／動的54通りランダム組み合わせ）設計＆操作ガイド

このUnityプロジェクト（**Unity 6000.3.23f1 / URP / OpenXR / Meta Quest 3対応**）は、以下の全仕様が自動構築・検証済みです。

---

## 1. コンセプト：『チープなAIホラーからの覚醒恐怖（2段階ギャップ演出）』

全シナリオ・全パターンにおいて、プレイヤーの心理を突く2段階の3Dモデル切り替え演出を採用しています。

1. **前半（1回目の鏡・遠景・序盤の写真やマネキン）**：
   * あえて**「こてこてのAI生成・プリミティブ組み合わせのチープなダミーモデル」**を出現させ、プレイヤーに「なんだ、チープなAIホラーゲームかｗ」と油断・安心させます。
2. **後半（後ろを振り返った瞬間・1階到着時・最後のクライマックス）**：
   * 油断して振り返った瞬間やクライマックスで、突如として**作り込まれた超高精細3Dモデル（`ScaryWoman_Ghost_01` / `elevator-apparition.glb`：全26パーツ・177,912頂点・335,134ポリゴン・濡れた乱れ髪・焦点の合わない目・血まみれの破れた白いドレス・崩れた顎）**が至近距離に現れ、強烈なギャップ恐怖を与えます。

## 2. ランダムシナリオ組み合わせシステム（プリセット12パターン ／ 動的組み合わせ全54通り）

起動シーン `00_BootScene.unity` の `ScenarioRandomizer` が、連続重複防止（シャッフルバッグ方式）で毎回異なるパターンを選択します。

* **案A：『深夜3時のエレベーター』（`01_ScenarioA_Elevator.unity`｜導入4種 × 中盤3種 × ラスト3種 ＝ 36通り）**

  * **Pattern 06**: 8階足音ダッシュ ＋ [閉]ボタン鏡警告 ＋ 1階偽の脱出→扉強制閉鎖＆背後襲撃

## 3. 操作方法（Meta Quest 3 実機 ＆ Unityエディタ共通）

* **VR実機（Meta Quest 3）**:
  * 点滅している3Dボタンに**コントローラー（手）を伸ばして直接触れる**か、**手を向けてトリガー／グリップを引く**とボタンを押せます（長押し対応）。
  * 実際に首を動かして「鏡を見る」「後ろを振り返る」「天井を見上げる」動作がHMDの角度でリアルタイムに判定されます。
* **PC / Unityエディタ上でのテスト**:
  * **視点回転**：ゲーム画面上で**マウス右ドラッグ**、または**矢印キー（`↑` `↓` `←` `→`）/ `WASD` キー**
  * **ボタン操作**：ボタンを**マウス左クリック（長押し対応）**、またはショートカットキー（`[1]`＝メインボタン/1階/現像/電力チャージ、`[C]`＝閉ボタン/ドアロック、`[E]`または`[Space]`＝非常ベル、`[O]`＝開ボタン）
